# 📷 Victor Zoza — Portfólio de Fotografia

Site portfólio desenvolvido para o fotógrafo **Victor Zoza**, com estética dark, galerias em masonry e efeitos de hover nas legendas das fotos.

## ✨ Sobre o projeto

Um site multi-página construído em HTML e CSS puro, com foco em apresentar o trabalho fotográfico de forma imersiva e elegante. Inclui background de tela cheia, transições suaves e organização visual em grade (masonry) para as galerias de imagens.

## 🎨 Funcionalidades

- Galeria em **masonry layout** com efeito de hover exibindo legendas
- Design **dark aesthetic** com imagem de fundo em tela cheia
- **13 páginas HTML** organizadas por categoria/projeto
- Imagens otimizadas em **WebP** (script Python + Pillow) com lazy loading, reduzindo tempo de carregamento

## 📁 Estrutura

```
zoza/
├── index.html
├── otimizadas/          # imagens convertidas para WebP
├── otimizar_imagens.py  # script de otimização das imagens
└── [demais páginas HTML]
```

## 🚀 Como rodar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/bchacon7/portfolio-victor-zoza.git
   ```
2. Abra o `index.html` no navegador (ou use a extensão Live Server do VS Code)
